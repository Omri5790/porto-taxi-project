# תוצאות ריצת אימות סינתטית — לא נתוני פורטו

כל הקבצים בתיקייה הזו הופקו מ**דאטהסט סינתטי** שנוצר על ידי
`tools/make_synthetic_h3.py` (20,000 נסיעות, עם עורקים מתוכננים מראש
ו"חור" מכוון באחד מהם), ולא מ־1.71M הנסיעות האמיתיות של פורטו.

**למה הם כאן:** כדי להוכיח שהאלגוריתמים של שלב 3 מוצאים את מה שהם אמורים
למצוא. מכיוון שאנחנו יודעים מראש מה שתלנו בנתונים, אפשר למדוד את הדיוק —
וזה מה ש־`tools/validate_results.py` בודק.

מה נמדד בריצה הזו:

| מדד | תוצאה |
|---|---|
| עורקים שתולים | 13–17 ק"מ |
| עורקים שהתגלו | עד 15.60 ק"מ |
| לולאות (מסלול שחוזר על תא) | 0 |
| tortuosity מקסימלי | 1.36 (סף 2.5) |
| מסלולים עם חורים | 44 |
| הערכת יתר של support — LSH | 9.0% |
| הערכת יתר של support — Suffix Array | 0.0% |
| הערכת יתר של support — Growth | 0.0% |

**התוצאות האמיתיות על נתוני פורטו ייכתבו ל־`output/` (הרמה מעל),**
אחרי ריצה של `scripts/run_pipeline_dataproc.sh` על Dataproc. עד שזה יקרה,
אין ב־`output/` שום קובץ תוצאות של שלב 3 — במכוון.

לשחזור הריצה הזו:

    bash run_local.sh --synthetic
